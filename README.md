### Что нового в версии 2.0:
- ✅ **Настоящий движок Xray-Core v26 (`libv2ray`)**: реальное туннелирование трафика через `VpnService` + `TUN` (`TCP REALITY`, `XHTTP REALITY`, `XTLS-Vision`).

- ✅ **Живой фоновый TCP-пинг**: автоматическая параллельная проверка реальной задержки серверов при запуске, импорте подписки и каждые 25 секунд.
